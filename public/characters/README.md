# キャラクター立ち絵の配置

このフォルダに **PNG画像** を以下のファイル名で配置してください。

| ファイル名 | 表示条件 | 推奨サイズ |
|---|---|---|
| `menhera_happy.png` | 全パラメータが高い（平均 > 70）= 満足顔 | 360×360 以上（縦長OK） |
| `menhera_normal.png` | バランス型 = 通常メンヘラ顔 | 同上 |
| `menhera_sad.png` | どれかが25未満 = 病んでる顔 | 同上 |
| `menhera_gameover.png` | ゲームオーバー時 | 同上 |

- 透過PNG推奨
- 縦長 (3:4 / 4:5) を推奨。`object-cover` で右側カラムにフィットします
- ファイルがなくても絵文字フォールバックで動作します（差し替え前提でOK）
