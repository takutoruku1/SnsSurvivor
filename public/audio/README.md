# BGM・効果音の配置

このフォルダに **MP3 または OGG 形式の音声ファイル** を以下のファイル名で配置してください。

## 🎵 BGM（ループ再生）

| ファイル名 | 用途 | 推奨尺 |
|---|---|---|
| `bgm_title.mp3` | タイトル画面 | 30〜60秒（ループ） |
| `bgm_play.mp3` | ゲーム中（メイン） | 60〜120秒（ループ） |
| `bgm_gameover.mp3` | ゲームオーバー画面 | 10〜20秒 |
| `bgm_clear.mp3` | クリア画面 | 10〜25秒 |

## 🔊 効果音（オプション・あとで対応）

| ファイル名 | 用途 |
|---|---|
| `se_post.mp3` | 投稿ボタン |
| `se_like.mp3` | いいね |
| `se_reply.mp3` | リプライ |
| `se_refresh.mp3` | TL更新 |
| `se_warning.mp3` | 欲求が0に近づいたとき |

## 📝 注意点

- **拡張子は `.mp3` 推奨**（ブラウザ互換性が最も高い）
- ファイル名は**完全一致**（小文字、アンダースコア）
- BGMは**ループ再生**されるので、冒頭と末尾を**クロスフェード処理**しておくと自然
- 推奨音量: **-14 LUFS** くらいに正規化しておくと環境差が出にくい
- ファイルがなくても、ゲームは無音で動作します（あくまで強化要素）

## 🛠️ 編集ツール

| ツール | 用途 |
|---|---|
| [Audacity](https://www.audacityteam.org/) | 無料、カット・フェード・音量調整 |
| [Sound Forge](https://www.magix.com/) | プロ向け |
| [Ocenaudio](https://www.ocenaudio.com/) | 軽量、初心者向け |

Audacityでのループ用クロスフェードのやり方:
1. ファイルを開く
2. 末尾の3〜5秒を選択 → `Effect > Fade Out`
3. 冒頭の3〜5秒を選択 → `Effect > Fade In`
4. 書き出し（`File > Export > Export As MP3`）

---

ファイルを置いたら、ゲーム側の音楽再生機能を実装します（音量スライダー・ミュートボタン付き）。
